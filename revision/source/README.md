# LaTeX sources of the manuscript and the Supplementary Information

Three files are compiled; every other `.tex` file here is read by them.

| File | Builds |
|---|---|
| `main.tex` | The manuscript in the journal's layout (`docs/assets/papers/manuscript.pdf`) |
| `supplement.tex` | The Supplementary Information (`docs/assets/papers/supplement.pdf`) |
| `reader.tex` | The two-column reading copy (`docs/assets/papers/reading-copy.pdf`) |

Build from this folder (the first line writes `si_refs.tex`, the numbers of the Supplementary notes, tables and
figures that the main text cites; the second pass reads them from the compiled supplement):

```bash
python ../../extension/synthesis/si_refs.py --out .
latexmk -pdf supplement.tex
python ../../extension/synthesis/si_refs.py --out . --aux supplement.aux
latexmk -pdf main.tex reader.tex
```

**Written by hand:** the text (`main.tex`, `supplement.tex`, and the Supplementary notes `ident_theory.tex` and
`*_methods.tex`), the overview figure (`overview_figure.tex`), `references.bib`, `results_macros.tex` (values of the
original release, which the text no longer cites), and the journal's class and bibliography style (`sn-jnl.cls`,
`sn-vancouver-num.bst`).

**Generated:** every file whose first line reads `% Generated by extension/...` is written from the result records
by the analysis code (`extension/synthesis/make_assets.py`, `registry.py` and `si_refs.py`, and each analysis's
`make_assets.py`). They hold the macros that carry every number (`*_macros.tex`), the figures (`*_figure.tex`) and
the tables (`*_table.tex`). Do not edit them by hand: `extension/verify_manuscript_assets.py` regenerates each one
and compares it byte for byte when its inputs are included; it reports the assets requiring omitted inputs.

Thirteen generated files are not read by the current manuscript: `cross_figure.tex`, `gen_figure.tex`,
`identified_figure.tex`, `identified_table.tex`, `pert_figure.tex`, `recov_auc_table.tex`, `recov_figure.tex`,
`recov_id_table.tex`, `recov_ref_table.tex`, `recov_table.tex`, `scale_figure.tex`, `scale_table.tex` and
`semi_figure.tex`. The analysis code still writes them, for earlier drafts, and the verifiers compare them, so they
stay.
